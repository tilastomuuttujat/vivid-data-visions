# Suomalaiset maailmalla: muuttoliikepoiminta

Lähde: Jouni Korkiasaari, [Suomalaiset maailmalla](https://www.doria.fi/handle/10024/180068), 1989, liitteet s. 159–160. Lähdesivut tarkistettu käyttäjän toimittamasta PDF:stä. 1980–1987 maahan- ja maastamuutto koskee Suomen kansalaisia; Ruotsi sisältyy kaikkien maiden summaan. Vuoden 1987 tiedot ovat teoksessa ennakollisia. Alkuperäinen tilastolähde on SVT VI A 1980–1987, osa 1. Lukuja ei pidä yhdistää kaikkia kansalaisuuksia käsittäviin sarjoihin tarkistamatta määritelmiä.

Kaukosiirtolaisuuden passiluettelo- ja matkustajaluetteloarviot 1870–1899 ovat toisistaan erillisiä eikä niitä summata. Jaksoarvot on tallennettu julkaisemattomiksi jaksotuen ja alkuperäislähteiden tarkistusta varten; vuoden numero on jakson pääteankkuri. Sarjat eivät syötä automaattista yhdistelmäindeksiä. `python build.py` tuottaa toistettavan erän ja idempotentin tuontiskriptin.
