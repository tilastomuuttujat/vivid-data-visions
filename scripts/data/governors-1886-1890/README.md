# Katsaus Suomen taloudelliseen tilaan 1886–1890

Rajattu poiminta [Tilastollisen toimiston vuoden 1894 julkaisusta](https://otos.stat.fi/items/5cba1161-e7f0-4daf-bc43-03fdc85896e4). Sivut ja käyttäjän toimittaman PDF:n SHA-256 ovat erän metatiedoissa. Poiminta sisältää rokotukset, pitäjänmakasiinien viljavarastot, yleisissä sairashuoneissa hoidetut sekä 1890 terveydenhuollon henkilöstöä ja rakenteita. Sarjat ovat historiallista kontekstia eivätkä automaattisen yhdistelmäindeksin syötteitä.

Vuoden 1888 rokotustaulukon luvut eivät vastaa lähteen prosentteja. Lähteen kolme lukumäärää säilytetään julkaisemattomina lisätarkistusta varten, eikä prosentteja tuoda. Makasiinien kirjanpidolliset ja fyysiset määrät ovat päällekkäisiä. Tämän lähteen yksikkö on hehtolitra, aikaisemmassa tynnyri. Lääkärien laillistettujen ja työskentelevien määrät eroavat käsitteellisesti; kätilöiden aiemman vuoden vertailuluku poikkeaa toisesta lähteestä. Vertailukelpoisuus on tarkistettava erikseen.

`python build.py` luo deterministisen batchin ja idempotentin tietokantatuonnin. Muuttunut sisältö edellyttää uutta erätunnusta.
