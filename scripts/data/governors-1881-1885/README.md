# Katsaus Suomenmaan taloudelliseen tilaan 1881–1885

Lähde: [Tilastollinen toimisto, 1890](https://otos.stat.fi/items/00e60816-094e-446a-b9a3-e0730976e36b). Käyttäjän toimittaman PDF:n SHA-256 on tallennettu erään. Lähdesivujen rokotus-, henkilökunta- ja makasiinitaulukot on tarkistettu PDF:n sivukuvista; viljakaupan viisivuotissummat ovat tekstisivuilla 35–36.

Poimintaan kuuluvat vuosittaiset rokotukset, valittujen viljalajien kirjanpidolliset ja makasiinissa olleet määrät, yleisten sairashuoneiden lasarettien hoitomäärät ja vuoden 1885 kaupunki–maaseutu-erittely. Viljakaupan 1881–1885 yhteissummat on tallennettu julkaisemattomiksi: vuosi 1885 on jakson pääteankkuri, ei vuosihavainto. Jauhot ja jauhamattomat jyvät pidetään eri yksiköissä.

Lähteen 1871–1875 jauhamattoman viljan tuonnin yhteenveto (880 358 tynnyriä) vastaa aiemman lähteen vientisummaa; aiemman lähteen tuontisumma on 399 627. Vanhat arvot säilytettiin, eikä ristiriitaa ratkaistu ilman lisätarkistusta. Sarjat eivät syötä automaattista yhdistelmäindeksiä.
