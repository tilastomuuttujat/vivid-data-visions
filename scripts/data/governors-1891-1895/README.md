# Katsaus Suomen taloudelliseen tilaan 1891–1895

Rajattu, sivukuvista tarkistettu poiminta vuoden 1899 julkaisusta. Lähteen URL, sivut ja käyttäjän toimittaman PDF:n SHA-256 tallennetaan erään. Havaintoja on 105 yhdeksässä sarjassa: viljavarastot, rokotukset, maanomistuksen kokoluokat, köyhäinhoidon kustannukset sekä terveydenhuollon rakenne.

Vuoden 1895 rokotustaulukon tarkastuksesta pois jääneiden 6 887 ei vastaa painettua 5,5 prosenttia rokotetuista. Havainto tallennetaan julkaisemattomana tarkistusta varten. Rokotusvelvollisten osuus ei ole suoraan vertailukelpoinen aiempaan syntyneisiin perustuvaan osuuteen.

Makasiineissa olleet varastot sisältyvät kirjanpidollisiin varoihin. Maanomistajat lasketaan kuntien ilmoituksista ja sama voi tulla useasti lasketuksi. Viljellyn alan luokka ei ole koko tilan pinta-ala. Köyhäinhoidon laajempi kustannusrajaus eroaa kuvernöörien suorien kulujen tiedoista. Historian aluerajat eroavat nykyisistä. Sarjat eivät ole automaattisen yhdistelmäindeksin syötteitä.
