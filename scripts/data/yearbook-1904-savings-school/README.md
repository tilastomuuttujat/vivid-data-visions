# Säästöpankit ja maaseudun kansakoulut

Poiminta vuoden 1904 Suomen tilastollisen vuosikirjan sivuilta 227 ja 292 (PDF-sivut 197 ja 242). Alkuperäisen PDF:n tarkistussumma on tallennettu erään. Säästöpankkikirjojen määrä ei välttämättä vastaa yksittäisiä säästäjiä. Kaupungit ja maaseutu sisältyvät koko maan lukuihin.

Lukuvuotta 1901–1902 koskevat maaseudun ylempien kansakoulujen koulu-, opettaja- ja oppilasmäärät säilytetään julkaisemattomina tarkistusvaiheessa: vuosi 1902 on jakson pääteankkuri eikä kalenterivuoden mittaus. Tiedot eivät kuvaa koko ikäluokkaa. Sarjat ovat kontekstitietoja, eivät automaattisen yhdistelmäindeksin syötteitä.
